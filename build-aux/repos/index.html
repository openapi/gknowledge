gknowledge packages

Signed package repositories for gknowledge, a native GNOME app that turns documents into a cited wiki. Add one once and updates arrive with the rest of your system.

Ubuntu and Debian (APT)

Ubuntu 24.04 or later, Debian 13 or later.

sudo curl -fsSLo /usr/share/keyrings/gknowledge.gpg @BASE_URL@/gknowledge.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/gknowledge.sources @BASE_URL@/gknowledge.sources
sudo apt update && sudo apt install gknowledge

To remove the repository: sudo rm /etc/apt/sources.list.d/gknowledge.sources /usr/share/keyrings/gknowledge.gpg

Any distribution (Flatpak)

The GNOME runtime is installed from Flathub automatically.

flatpak install --user @BASE_URL@/io.github.openapi.Gknowledge.flatpakref

Or add the remote: flatpak remote-add --user --if-not-exists gknowledge @BASE_URL@/gknowledge.flatpakrepo

Signing key

Both repositories are signed with the same key: gknowledge.asc.
